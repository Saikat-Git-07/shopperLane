🛍️ ShopperLane – MERN E-Commerce Application

ShopperLane is a full-stack MERN-based e-commerce web application.
The application allows users to browse products, add items to a cart, and enables an admin to manage products through a simple admin panel.

🚀 Tech Stack 
Frontend :

React.js

CSS

Component-based UI architecture

Backend :

Node.js

Express.js

RESTful APIs

Database :

MongoDB Atlas

Mongoose ODM

✨ Features

👤 User Features :

User signup and login

Product listing page

Product details page

Add products to cart

Cart page with selected items

🛒 Admin Features :

Admin panel

Add new products

Manage product listings

🔑 Environment Variables

The backend uses a .env file to store sensitive configuration data.

Example .env file:

MONGO_URI=your_mongodb_connection_string
PORT=5000


⚠️ The .env file is excluded from GitHub using .gitignore for security reasons.

🛠️ How to Run the Project :

1️⃣ Clone the repository
git clone https://github.com/your-username/shopperlane.git

2️⃣ Install backend dependencies
cd backend
npm install

3️⃣ Install frontend dependencies
cd ../frontend
npm install

4️⃣ Start the backend server
cd backend
npm start

5️⃣ Start the frontend
cd frontend
npm start
